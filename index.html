About the StreakIt! Educational Architecture

StreakIt! is designed without cumbersome external backend dependencies, running entirely natively in modern web browsers using standard HTML5 Canvas, Web Audio API synthesis, and local browser persistence. The simulation covers all six units of the standard undergraduate microbiology syllabus: History & Foundations, Growth & Culture Media, Metabolism & the Entner-Doudoroff Pathway, Horizontal Gene Transfer, Microbial Ecology, and Contamination Control/AMR.
